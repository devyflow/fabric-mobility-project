    Project on GitHub ↗

    3. GoldAggregate before joining pickups and monitors by local date and zone.

    Data sources & reproducibility

    Databricks produces the reporting snapshot. The map uses the same zone and date grain from the verified local build. Every map date reconciles with the published citywide trip count. Source rows with location codes outside the mapped polygons are included in citywide reporting.
